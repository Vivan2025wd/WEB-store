# 🛠 Roadmap for Your Store Platform MVP

---

## **Phase 1 – Project Setup**

🔹 Goal: Have a working skeleton with routing, styling, and backend server.

1. **Frontend Setup**

   * Install React + Vite + Tailwind
   * Setup file structure (`components/`, `pages/`, `services/`)
   * Create `App.jsx` with React Router (`/`, `/login`, `/dashboard`, `/create-store`, `/store/:id`)
   * Add `Navbar` + `Footer`

2. **Backend Setup**

   * Install Node.js + Express
   * Setup file structure (`models/`, `routes/`, `config/`)
   * Create `server.js` with test route (`/api/health`)
   * Setup database connection (`db.js`) → use **MongoDB (Mongoose)** or **Postgres (Prisma)**

✅ Deliverable: You can open `localhost:5173` for frontend, and `localhost:5000/api/health` for backend.

---

## **Phase 2 – Authentication (Seller Accounts)**

🔹 Goal: Allow sellers to register/login.

1. **Backend**

   * `User.js` model → `{ id, name, email, passwordHash }`
   * `authRoutes.js` → `/auth/register`, `/auth/login`
   * Use **bcrypt** for password hashing, **JWT** for sessions

2. **Frontend**

   * `login.jsx` → form for email + password
   * `auth.js` service → functions: `register()`, `login()`, `logout()`, `getCurrentUser()`
   * Store JWT in `localStorage`

✅ Deliverable: A seller can register/login and stay logged in.

---

## **Phase 3 – Store Creation**

🔹 Goal: Each seller can create and manage a store.

1. **Backend**

   * `Store.js` model → `{ id, ownerId, name, slug, logo, theme }`
   * `storeRoutes.js` → `/store/create`, `/store/:id`
   * Middleware: Ensure only store owner can edit their store

2. **Frontend**

   * `create-store.jsx` → form (store name, slug, logo upload, theme)
   * `dashboard.jsx` → show store details if one exists, or CTA to create a store

✅ Deliverable: A seller logs in → creates a store → sees it in their dashboard.

---

## **Phase 4 – Product Management**

🔹 Goal: Sellers add/manage products in their store.

1. **Backend**

   * `Product.js` model → `{ id, storeId, name, price, description, image }`
   * `productRoutes.js` → `/products/add`, `/products/:id/edit`, `/products/delete`

2. **Frontend**

   * `dashboard.jsx` → tab for “Products” (list existing, add new)
   * `ProductCard.jsx` → reusable component for showing products

✅ Deliverable: Seller can add products to their store and see them in their dashboard.

---

## **Phase 5 – Public Storefront**

🔹 Goal: Customers can browse seller stores.

1. **Backend**

   * `GET /store/:slug` → return store details + products

2. **Frontend**

   * `store/[storeId].jsx` → public storefront page
   * Show store branding + list of products with `ProductCard`
   * “Buy Now” button (will later link to checkout)

✅ Deliverable: Visiting `/store/sellername` shows their products publicly.

---

## **Phase 6 – Orders & Checkout**

🔹 Goal: Customers can buy products, payments are processed, and commission is taken.

1. **Backend**

   * `Order.js` model → `{ id, storeId, products, buyerInfo, total, commission }`
   * `orderRoutes.js` → `/order/create`, `/order/history`
   * `paymentRoutes.js` → Stripe Checkout Session
   * Commission logic: If order = $100 and commission = 10%, platform gets $10

2. **Frontend**

   * `payment.js` service → call backend to start Stripe Checkout
   * On successful checkout → redirect back with confirmation

✅ Deliverable: A buyer can checkout a product, payment is split (commission deducted), and order is saved.

---

## **Phase 7 – Admin & Commission Dashboard**

🔹 Goal: Platform owner can track revenue and commissions.

1. **Backend**

   * `Admin` role in `User.js`
   * Routes to fetch all sellers, stores, revenue stats

2. **Frontend**

   * `dashboard.jsx` (if admin) → show total revenue, commission earned, top sellers

✅ Deliverable: You (platform owner) can see total revenue and commissions.

---

# 🏁 MVP Complete!
